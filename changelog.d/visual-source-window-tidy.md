- **The source window and the Sources panel are tidier and consistent.** Every citation in the source window is a block of labelled rows (Person, Event, Link) with one divider between citations, an empty part shows only its header, a note is a row like the others and the part is called Citations. In the Sources panel an opened source shows labelled fields (Author, Publication, Notes, Links), the citations as Person, Event and Link, and Edit source as a pencil.
